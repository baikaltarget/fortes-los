# Переезд fortes-group.ru с Vercel на Бегет — пошагово (v44)

Зачем: часть российских провайдеров обрывает соединение с серверами Vercel (ошибка `ERR_CONNECTION_RESET`), и клиенты не могут открыть сайт. Теперь сайт будет лежать на Бегете, в России.

Что меняется для клиента: **ничего**. Тексты и цены правятся в GitHub так же (карандаш → Commit), через 3–5 минут правка на сайте.

Как это работает: GitHub после каждого коммита сам собирает сайт и загружает готовые файлы на Бегет по FTP. Vercel больше не нужен.

Весь переезд — примерно час работы плюс ожидание DNS. Лучше делать вечером.

---

## Часть 1. Бегет (панель cp.beget.com)

**1. Создать сайт.** Раздел **«Сайты»** → в поле нового сайта впишите `fortes-group.ru` → «Создать». Появится папка `fortes-group.ru/public_html`.

**2. Привязать домен.** Раздел **«Домены и поддомены»** → «Добавить существующий домен» → `fortes-group.ru` → направить на сайт из шага 1. Если Бегет предложит поменять DNS-серверы — **не меняйте**, это сделаем по-другому (шаг 9).

**3. Очистить папку.** **«Файловый менеджер»** → `fortes-group.ru/public_html` → удалите всё, что там лежит (обычно заглушка `index.php` или `index.html`).

**4. Создать FTP-доступ.** Раздел **«FTP»** → добавить аккаунт → папка **`fortes-group.ru/public_html`** → придумайте пароль. Запишите себе три вещи: адрес сервера (показан в разделе FTP, у вас `adminb46.beget.tech`), логин и пароль. Мне пароль не присылайте.

**5. Узнать IP-адрес.** На главной панели Бегета слева «Выделенные IP-адреса: 1» → нажмите, скопируйте IP (вида `87.236.xx.xx`). Он понадобится в шаге 9.

## Часть 2. GitHub (репозиторий baikaltarget/fortes-los)

**6. Положить ключи в сейф.** Settings → Secrets and variables → Actions → вкладка **Secrets** → New repository secret. Создайте по одной записи:

| Имя (Name) | Что вставить (Secret) |
|---|---|
| `FTP_SERVER` | адрес сервера из шага 4 (`adminb46.beget.tech`) |
| `FTP_USERNAME` | логин FTP из шага 4 |
| `FTP_PASSWORD` | пароль FTP из шага 4 |
| `TELEGRAM_BOT_TOKEN` | скопировать из Vercel: проект → Settings → Environment Variables → значок глаза |
| `TELEGRAM_CHAT_ID` | оттуда же |
| `AMO_SUBDOMAIN` | оттуда же, если есть |
| `AMO_TOKEN` | оттуда же, если есть |
| `LEAD_EMAIL` | почта, куда дублировать заявки (например, почта менеджера). **Очень советую** — см. «Важно про Telegram» ниже |

**7. Залить обновление v44.** Add file → Upload files → перетащить файлы из архива (кроме папки `.github`) → Commit.

Затем вручную:
- **Заменить файл расписания.** Откройте `.github/workflows/publish-scheduled.yml` → карандаш → выделите всё и удалите → вставьте содержимое такого же файла из архива → Commit.
- **Удалить старый обработчик заявок.** Откройте `app/api/lead/route.ts` → «…» справа вверху → Delete file → Commit.

**8. Проверить выкладку.** Вкладка **Actions** → «Сборка и выкладка на Бегет». Через 3–5 минут должна быть зелёная галочка. Если красный крестик — пришлите мне скрин ошибки. В файловом менеджере Бегета в `public_html` должны появиться файлы сайта.

⚠️ С этого момента на Vercel перестанет работать форма заявок. Поэтому шаг 9 делайте **в тот же день**, сразу после зелёной галочки.

## Часть 3. Переключить домен

**9. Направить домен на Бегет.** Идём туда, где сейчас управляют DNS домена `fortes-group.ru`. Если не знаете где — пришлите мне скрин, разберёмся. Если DNS в Vercel — это Vercel → Domains → fortes-group.ru.

**Перед изменением сделайте скрин всех записей** — это страховка.

Меняем **только две записи**, остальное (особенно MX — это почта) не трогаем:
- запись `A` для `fortes-group.ru` (или `@`) → IP Бегета из шага 5;
- запись для `www`: если это `CNAME` на Vercel — удалить и создать `A` → тот же IP.

Изменения расходятся от 15 минут до суток.

**10. Включить HTTPS.** Когда сайт начнёт открываться с Бегета (обычно через 1–3 часа): Бегет → «Домены и поддомены» → у `fortes-group.ru` значок SSL → бесплатный сертификат Let's Encrypt, отметить и `www`. Выпуск занимает до 30 минут.

После выпуска: GitHub → Settings → Secrets and variables → Actions → вкладка **Variables** → New repository variable: имя `FORCE_HTTPS`, значение `1`. Затем Actions → «Сборка и выкладка на Бегет» → Run workflow. Теперь все заходы по `http://` и `www.` будут автоматически переводиться на `https://fortes-group.ru`.

## Часть 4. Проверка

**11.** Попросите клиента открыть сайт с того интернета, где он не открывался.

**12.** Отправьте тестовую заявку с сайта (свой номер, в сообщении «тест»). Проверьте, пришла ли она в Telegram, в amoCRM и на почту.

**13.** Файл `fortes-group.ru/leads.log` в файловом менеджере Бегета — журнал всех заявок: что пришло и куда удалось доставить. Он есть только на сервере, из интернета не открывается.

**14.** Vercel: неделю не трогаем как запасной вариант, потом удаляем проект (Vercel → проект → Settings → внизу Delete Project).

---

## Важно про Telegram

С российских серверов адрес Telegram для ботов (`api.telegram.org`) сейчас часто недоступен. Если тестовая заявка не пришла в Telegram, а в `leads.log` написано «ошибка Telegram», это оно. Заявка при этом не теряется: она уходит в amoCRM и на почту из `LEAD_EMAIL` и всегда записывается в `leads.log`. Поэтому `LEAD_EMAIL` лучше указать сразу.

Вернуть Telegram можно через ретранслятор (адрес кладётся в секрет `TELEGRAM_API`) — напишите мне, если понадобится, настрою.
